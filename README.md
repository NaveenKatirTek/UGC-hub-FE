# Project Documentation

## Overview
This project is a web application designed to provide various functionalities, including an admin dashboard, campaign management, messaging center, and user verification. It utilizes React for building user interfaces and Tailwind CSS for styling.

## Folder Structure
- **public/**: Contains static assets such as images and fonts.
- **src/**: The main source code of the application.
  - **components/**: Reusable UI components.
    - **ui/**: Contains UI components like buttons, checkboxes, headers, inputs, selects, and sidebars.
  - **pages/**: Contains components for different pages of the application.
  - **styles/**: Contains global and Tailwind CSS styles.
  - **utils/**: Contains utility functions.
  - **App.jsx**: Main application component.
  - **index.jsx**: Entry point of the application.
  
## Installation
To install the project dependencies, run the following command:

```
npm install
```

## Usage
To start the development server, use the following command:

```
npm start
```
